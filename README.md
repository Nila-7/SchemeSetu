# SchemeSetu

### Bilingual Government Scheme Eligibility Finder

SchemeSetu is a web application that helps users discover government schemes based on their personal information and basic eligibility conditions.

The application provides a guided questionnaire, an explainable eligibility engine, scheme search and filtering, required document information, and links to official government portals.

SchemeSetu currently supports **English and Tamil**.

---

## 🚀 Project Overview

Finding the right government scheme can be difficult because users need to understand:

- Which schemes are relevant to them
- Whether they satisfy basic eligibility conditions
- What documents may be required
- What benefits a scheme provides
- Where to find the official application or information portal

SchemeSetu simplifies this process through a single guided interface.

---

## 🎯 Problem Statement

India has a large number of government welfare, financial assistance, skill development, livelihood, and support schemes.

However, users may face difficulties when:

- Scheme information is spread across different websites
- Eligibility conditions are difficult to understand
- Users are unsure which schemes apply to their situation
- Required documents are unclear
- Information may not be easily accessible in a preferred regional language

---

## 💡 Proposed Solution

SchemeSetu collects basic user information through a step-by-step questionnaire and evaluates the information against structured eligibility rules stored for each scheme.

The application then shows:

✅ Schemes that match the provided information  
📋 Eligibility checks  
📄 Common documents  
💰 Scheme benefits  
🔎 Search and category filtering  
🌐 Official government website links  
🇮🇳 English and Tamil language support  
❌ Reasons why other schemes did not match

# ✨ Key Features

## 🧑‍💻 Personalized Scheme Discovery

Users provide information such as:

- Age
- Gender
- Occupation
- Social category
- Annual income
- Agricultural landholding
- Business/self-employment information
- Scheme-specific information

The application evaluates this information against the stored eligibility rules.

---

## 🧠 Explainable Eligibility Engine

Instead of simply displaying:

> Eligible / Not Eligible

SchemeSetu shows the individual checks used during evaluation.

Example:

```text
✓ Age
  Meets the required age condition

✓ Occupation
  Matches the scheme's target occupation
